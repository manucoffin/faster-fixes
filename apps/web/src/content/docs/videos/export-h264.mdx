---
title: How to export H.264
description: Get an MP4 with H.264 video from an iPhone, a camera or editor, or a screen recorder, so it uploads and plays in every browser.
---

Faster Fixes accepts MP4 and MOV files with H.264 video. H.264 plays in every browser, so every Reviewer sees the same video. HEVC (H.265), ProRes and WebM are refused at upload because some browsers cannot play them.

Pick the section that matches where your video comes from.

## iPhone

Recent iPhones record in HEVC by default.

- **For future recordings**: open **Settings → Camera → Formats** and select **Most Compatible**. The iPhone then records H.264.
- **For a video you already recorded**: on a Mac, open it in QuickTime Player, choose **File → Export As**, pick a resolution, and select **Greater Compatibility (H.264)** when the option is shown.

## Camera or editor exports

- **From your editor**: export with the H.264 MP4 preset. In Premiere Pro, DaVinci Resolve or Final Cut Pro, choose MP4 as the format and H.264 as the video codec.
- **From a camera file**: open the original in [HandBrake](https://handbrake.fr), keep the MP4 format, set the video encoder to **H.264 (x264)**, and start the encode.

## Screen recordings

- **macOS**: QuickTime Player and the screenshot toolbar (**Shift-Command-5**) already produce H.264. Upload the file as is.
- **Windows**: the Game Bar (**Windows key + Alt + R**) already produces H.264. Upload the file as is.
- **Browser-based recorders**: most save WebM. Open the file in [HandBrake](https://handbrake.fr), choose MP4 with **H.264 (x264)**, and upload the result.

## Fast start

Turn on fast start, called **Web Optimized** in HandBrake and in some editors, when you export. It places the file index at the start so the review page can begin playback before the whole video has downloaded.
