---
title: Slack integration setup
description: Set up the Faster Fixes Slack integration to get notified in a Slack channel when feedback arrives or changes.
---

Faster Fixes posts to a Slack channel when feedback is created or its status changes. The integration only sends notifications and creates no issues. For issue tracking, use the [GitHub](/docs/integrations/github), [Linear](/docs/integrations/linear), [Jira](/docs/integrations/jira), or [Trello](/docs/integrations/trello) integrations. For a product overview, see the [Slack integration overview](/integrations/slack).

## Setup

1. Go to **[Application Settings](/integrations) → Integrations** from the sidebar
2. Click **Connect Slack** and authorize the Faster Fixes app on your workspace
3. In **[Project Settings](/settings) → Slack**, pick the channel that should receive feedback

The bot is installed once per organization, and each project links to one channel of that workspace. Changing a project's channel does not affect other projects.

## Channels

Public channels are listed in the dropdown. Private channels are supported only if the Faster Fixes bot is invited to them first.

## Messages

The diagnostic trail (DOM selector, browser info, console logs, network requests) is not included in the message. Follow its link to see it in the dashboard.

When the feedback has a [Recording](/docs/widget/recording), the message carries a **Play recording** button next to **Open in Faster Fixes**. The button opens the player in the dashboard and requires a login. The Recording's timeline is not included in the message.

The message for new feedback waits up to 30 seconds for the Recording to finish uploading, then is posted with or without the button. If the Recording is removed, the button disappears at the next status change.

## Disabling and disconnecting

Turn posting off per project from **[Project Settings](/settings) → Slack** without disconnecting. Disconnecting from **[Application Settings](/integrations) → Integrations** removes the workspace install and all project links. Existing Slack messages are not deleted and stop updating.
