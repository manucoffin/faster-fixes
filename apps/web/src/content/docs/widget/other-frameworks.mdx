## Script embed

The [script embed](/docs/widget/script-embed) installs the widget on any site with one `<script>` tag, including WordPress, Webflow, static HTML, and apps built with Vue, Angular or Svelte. It offers the same options and instance methods as the React embed. In a framework app, call `window.FasterFixes.init` from a mount hook, as shown in [Manual initialization](/docs/widget/script-embed#manual-initialization).

With a bundler, install `@fasterfixes/widget` and import `init` instead. See [Install from npm](/docs/widget/script-embed#install-from-npm).

## Headless client

To build your own feedback UI, use the core client directly:

```package-install
@fasterfixes/core
```

```ts
import { FasterFixesClient } from "@fasterfixes/core";

const client = new FasterFixesClient({
  apiKey: "proj_your_project_id",
  apiOrigin: "https://www.faster-fixes.com", // optional
});
```

The core package provides the API client, selector generation utilities, and browser info helpers without any framework dependency. See the [Feedback API](/docs/api-reference/feedback-api) for all available endpoints.
